# Reports

This folder stores optional review, QA, audit, or compliance reports produced
during project work.

## Naming Convention

Use clear, date-based names:

```text
qa-YYYY-MM-DD[-N].md
review-YYYY-MM-DD[-N].md
audit-YYYY-MM-DD[-N].md
```

Use the optional `-N` suffix when multiple reports are produced on the same day.

## Purpose

Reports should capture what was reviewed, what evidence was checked, what risks
remain, and what follow-up work is needed.
