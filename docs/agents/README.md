# Agent Workflow Reference

This directory contains optional guidance for teams that want a more structured
AI-agent workflow.

## Default Use

If you are using this repository as a normal backend + frontend starter, you do
not need to follow the agent-role files in this folder.

## Optional Use

If your project chooses to adopt an AI-agent workflow, use these files as a
starting point and trim them to match the stack and tooling you actually select.
