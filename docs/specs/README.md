# Specifications

This folder stores project specifications, implementation notes, and optional
reference material.

## Structure

```text
docs/specs/
|-- technical/        # Active technical specs for the current project
`-- incubator/        # Optional drafts, experiments, and future ideas
```

## How To Use It

- Put required project specs in `technical/`
- Put experimental or temporary ideas in `incubator/`
- Keep specs aligned with the implementation and ADRs

## Optional Reference Material

Some templates may include additional reference specs for AI-agent workflows or
other specialized patterns. Treat those as optional unless the current project
explicitly adopts them.
