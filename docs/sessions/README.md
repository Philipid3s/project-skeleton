# Session Notes

This folder stores optional handoff or continuity notes for long-running work.

## Purpose

Use these files when a task spans multiple sessions and you want a durable note
about the current state, open questions, or next steps.

## Naming Convention

```text
handoff-YYYY-MM-DD[-N].md
```

Use the optional `-N` suffix when multiple notes are written on the same day.

## When To Write One

- Before ending work that is still in progress
- When the context of a task is getting long
- After a major milestone, before the next phase
